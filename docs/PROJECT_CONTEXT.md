# PROJECT_CONTEXT.md — 長期文脈

## プロジェクト
ACT Hexaflex Mapper

## 目的
ACT（アクセプタンス＆コミットメント・セラピー）の6つのプロセスを手がかりに、観察内容とケースフォーミュレーション上の仮説を整理するオープンソース・プロトタイプ。

## 主な利用場面
- 匿名・架空ケースの整理
- 本人の言葉、観察事実、支援者の仮説、望む変化の区分
- ACT 6プロセスごとの観察・仮説マッピング
- 行動計画の整理

## 重要な設計原則
- 自動診断や未検証のスコアを提供しない。
- 観察事実、本人の言葉、支援者の仮説を区別する。
- 本人との共同検討を中心にする。
- 現段階では匿名・架空ケースのみを対象とする。
- AI・外部API・外部通信なしのローカル構成を維持する。

## 変更してはいけないもの
- 診断、緊急性判断、治療方針を自動決定する機能の追加。
- 匿名・架空ケース限定という現行方針を、審査なしに実在ケースへ拡張すること。
- 本人の言葉と支援者の解釈を混同するUI変更。
- ローカル完結という現行プライバシー方針の無断変更。

## 技術構成
- HTML / CSS / JavaScript
- ビルド不要
- 外部通信なし

## 安全・プライバシー
- 公開リポジトリに実症例・患者情報・未公開の業務情報を書かない。
- 実在ケース利用へ進む場合は、プライバシー・セキュリティ・組織運用を別途審査する。
